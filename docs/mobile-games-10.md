# 모바일 적합 유명 보드게임 10종 (설명·출처 포함)

선정 기준: 턴제(실시간 아님), 탭 터치로 조작 가능, 세로 화면에 들어감, 2~6인.
공식 모바일 앱 존재 여부도 함께 표기 (검증된 모바일 적합성).

## 1. 스컬 (Skull)

- 인원·시간: 3–6인, 15–45분
- 설명: 장미 3장+해골 1장씩 들고 시작. 돌아가며 앞면에 카드 1장씩 엎어 놓고,
  누군가 "장미 N장 뒤집을 수 있다"고 베팅 선언. 베팅이 돌면 최고 베팅자가
  자기 것부터 순서대로 N장 뒤집기. 해골 없이 성공하면 1점(2점 선승),
  해골 나오면 자기 카드 1장 잃음(상대가 랜덤으로 고름)
- 출처: NYT Wirecutter "18 Best Board Games of 2026" bluffing 1위,
  Wargamer best board games 2026, Hexagamers best bluffing
- 모바일: 베팅 숫자+/-, 카드 탭. 공식 앱급 UX로 만들기 쉬움
- 구현: 소. 상태(낸 카드, 베팅, 뒤집기 순서) 단순. 숨김 정보 view 패턴 재사용

## 2. 바퀴벌레 포커 (Cockroach Poker)

- 인원·시간: 2–6인, 20분
- 설명: 8종×8장=64장 나눠 갖기. 자기 카드를 남에게 엎어 밀며 종류 선언(진실/거짓).
  받은 사람은 맞히기(맞으면 준 사람이 가져감, 틀리면 자기가 가져감) 또는
  몰래 보고 다른 사람에게 넘기기(본 적 없는 사람에게만). 같은 종류 4장 모으면 탈락,
  낼 카드가 없어도 탈락. 최후 1인 제외 전원 승리
- 출처: 코리아보드게임즈 보드게임카페 규칙영상 재생수 3위(16,282회),
  Wikipedia "Cockroach Poker", devirgames.com 공식 룰
- 모바일: 밀기/맞히기/넘기기 전부 탭. 세로 리스트 UI로 충분
- 구현: 소~중. 넘기기 경로(seen 집합) 상태가 핵심. 숨김 view 필요

## 3. 러브레터 (Love Letter)

- 인원·시간: 2–4인, 20분
- 설명: 16장(8종: 경비·사제·남작·시녀·왕자·왕·백작·공주). 1장씩 들고 매 턴 1장 뽑고
  1장 내며 효과 해결. 탈락 또는 덱 소진 시 손패 숫자 최대자가 토큰 1개.
  토큰 먼저 모으면 승리. 2장 들고 하는 심리전이 핵심
- 출처: 공식 모바일 앱 존재 (Google Play "Love Letter - Strategy Card Game",
  App Store, Twin Sails, 온라인·AI 대전 지원) = 모바일 검증 완료
- 모바일: 공식 앱이 증명. 2장 패 UI라 화면 부담 제로
- 구현: 소. 16장 덱 + 8종 효과 switch. AI도 쉬움

## 4. 요트 다이스 (Yacht Dice)

- 인원·시간: 인원 무관, 15분
- 설명: 별도 기획서 없음 — 본 프로젝트 `docs/` 요트 조사 참조.
  주사위 5개 최대 3번 굴리기, 12칸(상단 6+보너스 35 / 하단 6) 기록, 총합 승부
- 출처: 코리아보드게임즈 카페 인기 7위, 51 Worldwide Games 수록,
  namu.wiki "요트(주사위)" 표준 점수표
- 모바일: 주사위 탭킵 + 굴리기 버튼. 세로 점수표 UI가 본체
- 구현: 소. 숨김 정보 없음. `randomInt` 서버 굴림

## 5. 우노 (Uno)

- 인원·시간: 2–10인, 20분
- 설명: 108장(4색 0–9 + 스킵·리버스·+2 + 와일드·+4). 같은 색/숫자/기호로 내기.
  한 장 남으면 "우노" 선언(잊으면 2장 페널티). 먼저 털면 승리, 점수 합산전 가능
- 출처: 코리아보드게임즈 카페 인기 6위(9,900회). 국민 카드게임이라 출처 생략 가능급
- 모바일: 공식 앱(Uno! by Mattel)이 전 세계 톱 매출 보드게임 — 모바일 적합성 끝판왕
- 구현: 중. 스택 방향, +2/+4 중첩 하우스룰 결정 필요, 색 선택 UI

## 6. 노 땡스 (No Thanks!)

- 인원·시간: 3–7인, 20분
- 설명: 3–35 숫자카드 33장 중 9장 제외, 칩 11개씩. 중앙 카드에 칩 올려 거부하거나
  카드+칩더미 가져가기. 연속 숫자는 최저값만 계산, 남은 칩은 -1점씩. 최저점 승리
- 출처: UltraBoardGames 공식 룰, BoardGameArena 정식 종목(BGA adaption 문서),
  Amigo/Thorsten Gimmler. BGA에서 검증된 온라인 플레이
- 모바일: 버튼 2개(가져가기/칩 올리기)가 게임의 전부. 세로 한 화면에 다 들어감
- 구현: 소. 공개 정보 100% (칩 숨김은 view에서 가리면 됨). AI: 기댓값 계산 쉬움

## 7. 라마 (LAMA)

- 인원·시간: 2–6인, 20분 (Knizia)
- 설명: 1–6×8장+라마8장=56장, 6장씩. 버림더미 top과 같은 숫자 or +1 내기
  (6 위엔 라마, 라마 위엔 라마/1). 못 내면 뽑기 or 포기(quit).
  전원 포기/털기 종료. 남은 패는 숫자합이 마이너스(같은 숫자 중복 1회 계산, 라마 10점).
  40점 모은 사람 생기면 최저점 승리. 털기 성공 시 토큰 1장 반환(10점 우선)
- 출처: UltraBoardGames 공식 룰, 1jour-1jeu 공식 룰북 PDF (Amigo)
- 모바일: 내기/뽑기/포기 3버튼 + 패 탭. BGA급 단순 UI
- 구현: 소. quit 상태, 라운드 종료 판정이 핵심. AI: 패 기댓값 쉬움

## 8. 젝스님트 (Take 6! / 6 nimmt!)

- 인원·시간: 2–10인, 45분 (2~3인도 잘 돌아감)
- 설명: 1–104 숫자카드. 10장씩 들고 4줄 seed. 매 턴 1장씩 동시 공개 →
  낮은 숫자부터, top보다 크면서 가장 작은 차이 줄의 끝에 붙임.
  6번째 카드를 놓게 되면 그 줄 5장을 전부 가져감(황소머리=마이너스).
  10턴 후 황소 최소가 승리
- 출처: Amigo/Wolfgang Kramer 고전. BGA 정식 종목. 국내 정발명 "젝스님트"
- 모바일: 동시 공개라 대기 시간 제로. 카드 1장 탭이 턴의 전부
- 구현: 소~중. 동시 액션 수집(전원 제출 후 일괄 해결) 패턴 필요 — 첫 사례라 구조 설계边 포함

## 9. 킹도미노 (Kingdomino)

- 인원·시간: 2–4인, 15분 (2인이 최고라는 평 다수)
- 설명: 지형+왕관 도미노 타일을 draft해서 5×5(2인은 7×7) 왕국 건설.
  같은 지형 연결 면적 × 왕관 수가 점수. draft 순서가 다음 턴 순서가 됨
- 출처: NYMag Strategist 2인 보드게임 전문가 추천 (Kingdomino 2인 변형 극찬),
  2017 Spiel des Jahres 수상작
- 모바일: 타일 탭→배치 탭. 격자 UI라 터치 궁합 좋음
- 구현: 중. 배치 합법성(지형 매칭/5×5 경계) + 점수 계산(연결요소×왕관)

## 10. 익스플로딩 키튼 (Exploding Kittens)

- 인원·시간: 2–5인, 15분
- 설명: 덱에서 카드 뽑기. 폭탄 뽑으면 해제 카드 없으면 탈락.
  나머지 카드는 스킵·공격·호의·예언·셔플·Nope 등으로 생존 조작. 최후 1인 승리
- 출처: 킥스타터 역대 최다 펀딩 보드게임. 공식 모바일 앱 2종
  (Google Play "Exploding Kittens 2", App Store, Marmalade, 온라인·AI 지원)
- 모바일: 공식 앱이 수백만 DL — 검증 끝. 카드 탭+뽑기 버튼
- 구현: 중. 카드 효과 10종 + Nope 체인(우선권 스택)이 핵심. IP 주의: 아트·명칭은
  오마주 수준으로 바꾸고 메커닉만 차용 (폭탄→지뢰 등)

## 우선순위 제안 (모바일+구현비+잼 종합)

1. 바퀴벌레 포커 — 카페 검증+구현 소+블러핑 라인업 강화(쿠데타와 궁합)
2. 노 땡스 — BGA 검증+구현 최소+3인 이상 필러
3. 라마 — Knizia+구현 최소+quit 심리전
4. 러브레터 — 공식 앱 검증+구현 소
5. 스컬 — 세계 1위 블러핑이나 3인↓ 약함. 4인 모임용
